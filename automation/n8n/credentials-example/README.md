# n8n Credential Examples
#
# This directory contains example credential configuration structures.
# Never store actual credentials here.
# 
# Credential types used by RunbookOS workflows:
#
# - HTTP Header Auth (for Spring Boot internal API)
# - Slack OAuth2 (for notifications and approvals)
# - GitHub App (for repository access)
# - SMTP (for email notifications)
# - Generic HTTP Request (for health checks)
